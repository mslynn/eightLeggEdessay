## 5. 低代码平台中如何实现组件通信?

**答案:**

低代码平台中的组件通信主要有以下几种方式:

### 1. Props传递(父→子)
```json
{
  "type": "Container",
  "children": [
    {
      "type": "Button",
      "props": {
        "text": "${parent.buttonText}",
        "onClick": "${parent.handleButtonClick}"
      }
    }
  ]
}
```

### 2. 事件冒泡(子→父)
```javascript
// 子组件触发事件
emit('change', { value: newValue });

// 父组件监听事件
{
  "type": "Input",
  "events": {
    "onChange": "${handleInputChange}"
  }
}
```

### 3. 全局状态管理
使用全局Store或状态管理方案:

```javascript
// 状态定义
const store = {
  state: {
    userInfo: null,
    theme: 'light'
  },
  mutations: {
    setUserInfo(state, payload) {
      state.userInfo = payload;
    }
  },
  actions: {
    async fetchUserInfo({ commit }) {
      const user = await api.getUser();
      commit('setUserInfo', user);
    }
  }
};

// 组件中使用
{
  "type": "Text",
  "text": "${store.state.userInfo.name}"
}
```

### 4. 事件总线(EventBus)
```javascript
// 发送事件
EventBus.emit('user-login', { userId: 123 });

// 监听事件
EventBus.on('user-login', (data) => {
  console.log('用户登录:', data);
});

// 在Schema中使用
{
  "type": "Button",
  "events": {
    "onClick": "EventBus.emit('custom-event', { value: 123 })"
  }
}
```

### 5. 数据源绑定
通过数据源实现组件间的数据共享:

```json
{
  "dataSource": {
    "id": "user-data",
    "type": "api",
    "url": "/api/user/info",
    "autoFetch": true
  },
  "components": [
    {
      "type": "Text",
      "text": "${user-data.name}"
    },
    {
      "type": "Avatar",
      "src": "${user-data.avatar}"
    }
  ]
}
```

### 6. 表单联动
```javascript
// 监听字段变化
{
  "type": "Select",
  "props": {
    "options": [
      { "label": "北京", "value": "beijing" },
      { "label": "上海", "value": "shanghai" }
    ]
  },
  "events": {
    "onChange": "updateCityDistricts($event)"
  }
}
```
