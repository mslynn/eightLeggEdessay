# 低代码平台面试题集锦

## 1. 什么是低代码平台?低代码平台的优势和劣势是什么?

**答案:**

低代码平台(Low-Code Platform)是一种应用开发平台,允许开发者通过图形化界面、拖拽组件、可视化配置等方式,以最少的手写代码来快速构建应用程序。

### 优势:
1. **开发效率高**: 通过可视化拖拽和配置,大幅减少手写代码量,开发效率提升5-10倍
2. **降低门槛**: 业务人员也能参与应用开发,无需深入的编程技能
3. **快速迭代**: 支持快速原型设计和敏捷开发,便于业务需求快速响应
4. **标准化**: 统一的组件库和开发规范,保证应用质量一致性
5. **降低成本**: 减少对专业开发人员的依赖,降低开发和维护成本
6. **易于维护**: 可视化的配置便于理解和管理,降低维护难度

### 劣势:
1. **灵活性受限**: 平台提供的功能可能无法满足所有复杂业务场景
2. **性能瓶颈**: 通用化的组件和运行时可能不如定制化代码高效
3. **供应商锁定**: 依赖特定平台的技术栈和生态,迁移成本高
4. **学习成本**: 仍需学习平台特定的概念和操作方式
5. **调试困难**: 可视化配置的错误排查比代码调试更困难
6. **定制能力**: 对于高度定制化的需求,仍需编写自定义代码

## 2. 低代码平台的核心技术架构有哪些层次?

**答案:**

低代码平台通常包含以下核心层次:

### 1. 配置协议层(DSL层)
- 定义平台能够理解的 JSON Schema 结构
- 描述页面结构、组件属性、事件绑定等
- 是平台的基石,决定了平台的扩展能力

### 2. 可视化设计层(Designer)
- 提供拖拽、排序、选中、配置属性的可视化操作界面
- 核心功能:组件面板、画布区域、属性配置面板
- 实时预览和所见即所得

### 3. 渲染引擎层(Renderer)
- 负责将 DSL 转换为真实的页面或应用
- 支持多种渲染模式:设计态渲染、预览态渲染、发布态渲染
- 动态组件加载和生命周期管理

### 4. 出码引擎层(Code Generator)
- 将 DSL 转换为可执行的源代码
- 支持多种技术栈:React、Vue、Angular等
- 支持项目级别的代码生成

### 5. 物料层(Material)
- 标准组件库:基础UI组件(Button、Input、Table等)
- 业务组件库:封装了业务逻辑的复杂组件
- 区块(Block):预置的页面片段或布局

### 6. 插件体系(Plugin System)
- 提供扩展能力,支持自定义组件、面板、工具
- 支持第三方开发者贡献物料

### 7. 数据层(Data Layer)
- 数据源管理:API、数据库、消息队列等
- 数据绑定和表达式引擎
- 状态管理和数据流转

## 3. 请简述低代码平台的拖拽实现原理

**答案:**

低代码平台的拖拽实现主要包括以下几个关键点:

### 1. 拖拽事件监听
使用 HTML5 Drag and Drop API 或第三方库(如react-dnd、dnd-kit):

```javascript
// 开始拖拽
const handleDragStart = (e, component) => {
  e.dataTransfer.setData('component', JSON.stringify(component));
  e.dataTransfer.effectAllowed = 'copy';
};

// 拖拽经过
const handleDragOver = (e) => {
  e.preventDefault();
  e.dataTransfer.dropEffect = 'copy';
};

// 放置
const handleDrop = (e) => {
  e.preventDefault();
  const component = JSON.parse(e.dataTransfer.getData('component'));
  // 将组件添加到页面结构中
};
```

### 2. 拖拽定位
在拖拽过程中实时探测组件的可插入位置:

- **辅助线显示**:显示组件将要插入的位置
- **位置计算**:基于鼠标位置计算插入的索引
- **碰撞检测**:判断组件是否可以插入到目标位置

### 3. 跨iframe拖拽
当组件面板和画布在不同的iframe中时:

- 使用 postMessage 进行跨窗口通信
- 统一拖拽坐标系,处理坐标转换
- 传输拖拽数据和状态

### 4. 拖拽状态管理
- **拖拽中**:显示占位符和辅助线
- **悬停**:高亮可放置区域
- **释放**:执行插入操作并更新数据

### 5. 优化考虑
- **节流**:减少拖拽过程中的计算频率
- **虚拟滚动**:处理大量组件时的性能优化
- **拖拽预览**:生成组件的预览图

## 4. 什么是DSL(领域特定语言)?低代码平台中如何设计Schema?

**答案:**

### DSL(领域特定语言)
DSL是为特定领域设计的编程语言或描述语言,比通用编程语言更专注和简洁。在低代码平台中,DSL通常以JSON格式描述页面结构和组件配置。

### Schema设计原则
1. **完整性**:能够描述所有支持的页面元素和配置
2. **可扩展性**:支持新增组件和属性
3. **可读性**:便于人工理解和调试
4. **版本化**:支持Schema升级和兼容

### Schema结构示例

```json
{
  "version": "1.0.0",
  "pageId": "page-001",
  "pageName": "示例页面",
  "components": [
    {
      "id": "container-001",
      "type": "Container",
      "props": {
        "style": {
          "width": "100%",
          "padding": "20px"
        }
      },
      "children": [
        {
          "id": "button-001",
          "type": "Button",
          "props": {
            "text": "点击我",
            "type": "primary",
            "onClick": "${handleClick}"
          }
        }
      ]
    }
  ],
  "dataSource": {
    "api": "/api/data",
    "method": "GET"
  },
  "globalStyle": {
    "backgroundColor": "#f0f0f0"
  }
}
```

### 关键设计点

#### 1. 组件描述
- `id`: 唯一标识
- `type`: 组件类型
- `props`: 组件属性
- `children`: 子组件
- `events`: 事件绑定

#### 2. 数据绑定
- 使用 `${expression}` 语法绑定数据
- 支持表达式引擎,如:
```json
{
  "text": "${user.name + ' - ' + user.age}"
}
```

#### 3. 条件渲染
```json
{
  "visible": "${user.role === 'admin'}"
}
```

#### 4. 循环渲染
```json
{
  "type": "List",
  "dataSource": "${users}",
  "renderItem": {
    "type": "Text",
    "text": "${item.name}"
  }
}
```

## 6. 什么是出码(Code Generation)?低代码平台如何实现出码?

**答案:**

### 出码(Code Generation)
出码是指将低代码平台的DSL(JSON Schema)转换为可执行的源代码的过程。出码使得低代码平台可以输出标准化的代码,方便集成到现有的开发流程中。

### 出码流程

#### 1. 解析DSL
```javascript
function parseSchema(schema) {
  // 解析页面结构
  const page = {
    components: [],
    dataSource: schema.dataSource,
    globalStyle: schema.globalStyle
  };
  
  // 递归解析组件树
  schema.components.forEach(comp => {
    page.components.push(parseComponent(comp));
  });
  
  return page;
}
```

#### 2. 生成代码模板
```javascript
// React模板示例
function generateReactCode(parsedData) {
  return `
import React from 'react';
import { Button, Input, Table } from 'antd';

const ${parsedData.pageName} = () => {
  const [state, setState] = React.useState({
    ${parsedData.state.join(',\n    ')}
  });

  return (
    <div style={${JSON.stringify(parsedData.globalStyle)}}>
      ${generateComponents(parsedData.components)}
    </div>
  );
};

export default ${parsedData.pageName};
  `;
}
```

#### 3. 组件代码生成
```javascript
function generateComponents(components) {
  return components.map(comp => {
    switch(comp.type) {
      case 'Button':
        return `<Button 
          type="${comp.props.type}"
          onClick={${comp.props.onClick}}
        >
          ${comp.props.text}
        </Button>`;
      case 'Container':
        return `<div style={${JSON.stringify(comp.props.style)}}>
          ${generateComponents(comp.children)}
        </div>`;
      default:
        return `<${comp.type} {...${JSON.stringify(comp.props)}} />`;
    }
  }).join('\n');
}
```

#### 4. 数据源代码生成
```javascript
function generateDataSource(dataSource) {
  return `
  const [data, setData] = React.useState(null);
  
  React.useEffect(() => {
    fetch('${dataSource.url}', {
      method: '${dataSource.method}'
    })
    .then(res => res.json())
    .then(setData);
  }, []);
  `;
}
```

### 出码策略

#### 1. 完整项目出码
- 生成完整的项目结构
- 包含路由、状态管理、API封装等
- 可直接部署

#### 2. 页面级别出码
- 只生成单个页面的组件代码
- 需要手动集成到现有项目

#### 3. 组件级别出码
- 生成可复用的组件代码
- 支持组件库导出

### 出码优化

#### 1. 代码美化
- 使用Prettier格式化代码
- 统一代码风格

#### 2. 类型支持
- 生成TypeScript类型定义
- 提供类型提示

#### 3. 性能优化
- 添加React.memo、useMemo等优化
- 按需加载组件

#### 4. 可读性
- 添加注释
- 使用有意义的变量名

```javascript
class FormValidator {
  constructor(rules) {
    this.rules = rules;
  }
  
  async validate(value, fieldId) {
    const fieldRules = this.rules[fieldId] || [];
    const errors = [];
    
    for (const rule of fieldRules) {
      const error = await this.validateRule(value, rule);
      if (error) {
        errors.push(error);
      }
    }
    
    return errors;
  }
  
  async validateRule(value, rule) {
    switch (rule.type) {
      case 'required':
        if (!value || value.trim() === '') {
          return rule.message;
        }
        break;
      case 'pattern':
        if (!new RegExp(rule.value).test(value)) {
          return rule.message;
        }
        break;
      case 'email':
        if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(value)) {
          return rule.message;
        }
        break;
      case 'min':
        if (value.length < rule.value) {
          return rule.message;
        }
        break;
      case 'max':
        if (value.length > rule.value) {
          return rule.message;
        }
        break;
    }
  }
}
```

## 8. 低代码平台中如何实现页面渲染引擎?

**答案:**

页面渲染引擎是低代码平台的核心,负责将DSL转换为真实的页面。以下是实现要点:

### 1. 组件映射表

```javascript
const componentMap = {
  // 基础组件
  'Container': Container,
  'Button': Button,
  'Input': Input,
  'Text': Text,
  'Image': Image,
  'Table': Table,
  
  // 表单组件
  'Form': Form,
  'FormItem': FormItem,
  'Select': Select,
  'DatePicker': DatePicker,
  
  // 业务组件
  'UserCard': UserCard,
  'ProductList': ProductList
};
```

### 2. 递归渲染组件

```javascript
function renderComponent(component, context) {
  const Component = componentMap[component.type];
  
  if (!Component) {
    console.warn(`未找到组件: ${component.type}`);
    return null;
  }
  
  // 处理子组件
  const children = component.children
    ? component.children.map(child => renderComponent(child, context))
    : component.props?.children;
  
  // 处理属性
  const props = {
    ...component.props,
    children,
    // 注入上下文
    ...context
  };
  
  // 处理事件
  Object.keys(component.events || {}).forEach(eventName => {
    props[eventName] = (e) => {
      const handler = eval(component.events[eventName]);
      handler(e, context);
    };
  });
  
  return <Component key={component.id} {...props} />;
}
```

### 3. 页面级渲染

```javascript
function renderPage(schema) {
  // 初始化上下文
  const context = {
    state: {},
    dataSource: schema.dataSource,
    globalStyle: schema.globalStyle
  };
  
  // 加载数据源
  if (context.dataSource) {
    loadDataSource(context.dataSource, context);
  }
  
  // 渲染组件树
  const components = schema.components.map(comp => 
    renderComponent(comp, context)
  );
  
  return (
    <div style={context.globalStyle}>
      {components}
    </div>
  );
}
```

### 4. 数据源加载

```javascript
async function loadDataSource(dataSource, context) {
  try {
    const response = await fetch(dataSource.url, {
      method: dataSource.method,
      headers: dataSource.headers
    });
    const data = await response.json();
    context.state[dataSource.id || 'data'] = data;
    
    // 触发重新渲染
    forceUpdate();
  } catch (error) {
    console.error('加载数据源失败:', error);
  }
}
```

```javascript
function evaluateExpression(expression, context) {
```

```javascript
class GlobalStore {
  constructor() {
    this.state = {};
    this.listeners = [];
    this.mutations = {};
    this.actions = {};
  }
  
  // 获取状态
  getState(key) {
    return key ? this.state[key] : this.state;
  }
  
  // 设置状态
  setState(key, value) {
    this.state[key] = value;
    this.notify();
  }
  
  // 注册变更监听
  subscribe(listener) {
    this.listeners.push(listener);
    return () => {
      const index = this.listeners.indexOf(listener);
      this.listeners.splice(index, 1);
    };
  }
  
  // 通知变更
  notify() {
    this.listeners.forEach(listener => listener(this.state));
  }
  
  // 注册mutation
  registerMutation(name, handler) {
    this.mutations[name] = handler;
  }
  
  // 执行mutation
  commit(name, payload) {
    if (this.mutations[name]) {
      this.mutations[name](this.state, payload);
      this.notify();
    }
  }
  
  // 注册action
  registerAction(name, handler) {
    this.actions[name] = handler;
  }
  
  // 执行action
  async dispatch(name, payload) {
    if (this.actions[name]) {
      await this.actions[name]({ state: this.state, commit: this.commit.bind(this) }, payload);
    }
  }
}
```

```javascript
class HistoryStore extends GlobalStore {
  constructor() {
    super();
    this.history = [];
    this.currentIndex = -1;
    this.maxHistory = 50;
  }
  
  // 记录状态快照
  recordSnapshot() {
    const snapshot = JSON.parse(JSON.stringify(this.state));
    
    // 删除当前位置之后的历史
    this.history = this.history.slice(0, this.currentIndex + 1);
    
    // 添加新快照
    this.history.push(snapshot);
    
    // 限制历史长度
    if (this.history.length > this.maxHistory) {
      this.history.shift();
    } else {
      this.currentIndex++;
    }
  }
  
  // 撤销
  undo() {
    if (this.currentIndex > 0) {
      this.currentIndex--;
      this.state = JSON.parse(JSON.stringify(this.history[this.currentIndex]));
      this.notify();
    }
  }
  
  // 重做
  redo() {
    if (this.currentIndex < this.history.length - 1) {
      this.currentIndex++;
      this.state = JSON.parse(JSON.stringify(this.history[this.currentIndex]));
      this.notify();
    }
  }
```

```javascript
    // 初始化插件

        plugin.destroy();

    }

    return this.plugins.get(pluginId);
```

```javascript
class PreviewEngine {
  constructor(container) {
    this.container = container;
    this.iframe = null;
    this.port = null;
  }
  
  // 创建预览iframe
  createIframe() {
    this.iframe = document.createElement('iframe');
    this.iframe.style.width = '100%';
    this.iframe.style.height = '100%';
    this.iframe.style.border = 'none';
    this.container.appendChild(this.iframe);
    
    // 等待iframe加载完成
    return new Promise((resolve) => {
      this.iframe.onload = () => {
        // 建立通信通道
        this.port = this.iframe.contentWindow;
        this.setupMessageChannel();
        resolve();
      };
      
      // 加载预览页面
      this.iframe.src = '/preview.html';
    });
  }
  
  // 建立消息通道
  setupMessageChannel() {
    // 监听来自iframe的消息
    window.addEventListener('message', (event) => {
      if (event.source === this.port) {
        this.handleMessage(event.data);
      }
    });
  }
  
  // 发送消息到iframe
  sendMessage(type, payload) {
    if (this.port) {
      this.port.postMessage({ type, payload }, '*');
    }
  }
  
  // 更新预览内容
  updatePreview(schema) {
    this.sendMessage('UPDATE_SCHEMA', schema);
  }
  
  // 处理来自iframe的消息
  handleMessage(data) {
    switch (data.type) {
      case 'READY':
        console.log('预览iframe已就绪');
        break;
      case 'COMPONENT_CLICK':
        // 通知主应用组件被点击
        this.emit('component-click', data.payload);
        break;
      case 'COMPONENT_HOVER':
        // 通知主应用组件被悬停
        this.emit('component-hover', data.payload);
        break;
    }
  }
}
```

```javascript
class PreviewRenderer {
  constructor() {
    this.schema = null;
    this.componentMap = {};
  }
  
  // 注册组件
  registerComponent(type, component) {
    this.componentMap[type] = component;
  }
  
  // 渲染Schema
  render(schema, container) {
    this.schema = schema;
    container.innerHTML = '';
    
    // 递归渲染组件
    schema.components.forEach(comp => {
      const element = this.renderComponent(comp);
      container.appendChild(element);
    });
  }
  
  // 渲染组件
  renderComponent(component) {
    const Component = this.componentMap[component.type];
    
    if (!Component) {
      console.warn(`未找到组件: ${component.type}`);
      return document.createElement('div');
    }
    
    // 创建DOM元素
    const element = Component.createElement(component);
    
    // 处理子组件
    if (component.children) {
      component.children.forEach(child => {
        const childElement = this.renderComponent(child);
        element.appendChild(childElement);
      });
    }
    
    // 添加事件监听
    if (component.events) {
      Object.keys(component.events).forEach(eventName => {
        element.addEventListener(eventName, (e) => {
          const handler = new Function('e', component.events[eventName]);
          handler(e);
          
          // 通知父窗口
          window.parent.postMessage({
            type: 'COMPONENT_EVENT',
            payload: {
              componentId: component.id,
              eventName,
              data: e
            }
          }, '*');
        });
      });
    }
    
    // 添加悬停事件
    element.addEventListener('mouseenter', () => {
      window.parent.postMessage({
        type: 'COMPONENT_HOVER',
        payload: { componentId: component.id }
      }, '*');
    });
    
    element.addEventListener('click', (e) => {
      e.stopPropagation();
      window.parent.postMessage({
        type: 'COMPONENT_CLICK',
        payload: { componentId: component.id }
      }, '*');
    });
    
    return element;
  }
}
```

```javascript
  constructor() {

    this.maxVersions = 100;

  // 创建新版本
  createVersion(schema, options = {}) {

      schema: schema,
      snapshot: this.createSnapshot(schema),
      createdBy: options.createdBy || 'anonymous',
      description: options.description || '',
      tags: options.tags || []
    });
    
    this.versions.push(version);
    this.currentVersion = version;

      this.versions.shift();
    }
    
    return version;
  }
  
  // 创建快照
  createSnapshot(schema) {
    // 使用JSON序列化创建快照
    return JSON.stringify(schema);
  }
  
  // 获取当前版本
  getCurrentVersion() {
    return this.currentVersion;
  }

  getAllVersions() {
    return this.versions;

    return this.versions.find(v => v.id === id);

  // 比较两个版本的差异
  compareVersions(versionId1, versionId2) {
    const v1 = this.getVersionById(versionId1);
    const v2 = this.getVersionById(versionId2);
    
    if (!v1 || !v2) {
      throw new Error('版本不存在');
    }
    
    // 计算差异
    const diff = this.computeDiff(v1.schema, v2.schema);
    return diff;
  }
  
  // 计算Schema差异
  computeDiff(schema1, schema2) {
    const diff = {
      added: [],
      removed: [],
      modified: []
    };
    
    // 比较组件
    const components1 = this.indexComponents(schema1.components);
    const components2 = this.indexComponents(schema2.components);
    
    // 查找新增的组件
    Object.keys(components2).forEach(id => {
      if (!components1[id]) {
        diff.added.push(components2[id]);
      }
    });
    
    // 查找删除的组件
    Object.keys(components1).forEach(id => {
      if (!components2[id]) {
        diff.removed.push(components1[id]);
      }
    });
    
    // 查找修改的组件
    Object.keys(components2).forEach(id => {
      if (components1[id] && JSON.stringify(components1[id]) !== JSON.stringify(components2[id])) {
        diff.modified.push({
          id,
          old: components1[id],
          new: components2[id]
        });
      }
    });
    
    return diff;
  }
  
  // 索引组件
  indexComponents(components) {
    const index = {};
    
    function traverse(comps) {
      comps.forEach(comp => {
        index[comp.id] = comp;
        if (comp.children) {
          traverse(comp.children);
        }
      });
    }
    
    traverse(components);
    return index;
  }
}
```

```javascript
class DataSource {
  constructor(data) {
    this.id = data.id;
    this.name = data.name;
    this.type = data.type;
    this.config = data.config;
    this.transform = data.transform;
    this.cache = data.cache || {};
    this.errorHandler = data.errorHandler;
  }
  
  // 执行数据源
  async execute(context = {}) {
    try {
      let data;
      
      switch (this.type) {
        case DataSourceTypes.API:
          data = await this.executeApi(context);
          break;
        case DataSourceTypes.GRAPHQL:
          data = await this.executeGraphQL(context);
          break;
        case DataSourceTypes.MOCK:
          data = this.executeMock(context);
          break;
        case DataSourceTypes.STATIC:
          data = this.config.data;
          break;
        default:
          throw new Error(`不支持的数据源类型: ${this.type}`);
      }
      
      // 数据转换
      if (this.transform) {
        data = this.transform(data, context);
      }
      
      return data;
    } catch (error) {
      if (this.errorHandler) {
        return this.errorHandler(error, context);
      }
      throw error;
    }
  }
  
  // 执行API请求
  async executeApi(context) {
    const { method = DataSourceMethods.GET, url, headers, params, body } = this.config;
    
    // 替换URL中的变量
    const finalUrl = this.replaceVariables(url, context);
    
    // 替换参数中的变量
    const finalParams = this.replaceVariables(params, context);
    
    const options = {
      method,
      headers: {
        'Content-Type': 'application/json',
        ...headers
      }
    };
    
    if (body && method !== DataSourceMethods.GET) {
      options.body = JSON.stringify(this.replaceVariables(body, context));
    }
    
    // 构建查询参数
    const queryString = new URLSearchParams(finalParams).toString();
    const finalUrlWithQuery = queryString ? `${finalUrl}?${queryString}` : finalUrl;
    
    const response = await fetch(finalUrlWithQuery, options);
    
    if (!response.ok) {
      throw new Error(`请求失败: ${response.status} ${response.statusText}`);
    }
    
    return response.json();
  }
  
  // 执行GraphQL请求
  async executeGraphQL(context) {
    const { url, query, variables } = this.config;
    
    const response = await fetch(url, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        query: this.replaceVariables(query, context),
        variables: this.replaceVariables(variables, context)
      })
    });
    
    return response.json();
  }
  
  // 执行Mock数据
  executeMock(context) {
    const { data } = this.config;
    return this.replaceVariables(data, context);
  }
  
  // 替换变量
  replaceVariables(obj, context) {
    if (typeof obj === 'string') {
      return obj.replace(/\$\{([^}]+)\}/g, (match, path) => {
        return this.getValueByPath(context, path);
      });
    }
    
    if (Array.isArray(obj)) {
      return obj.map(item => this.replaceVariables(item, context));
    }
    
    if (typeof obj === 'object' && obj !== null) {
      const result = {};
      Object.keys(obj).forEach(key => {
        result[key] = this.replaceVariables(obj[key], context);
      });
      return result;
    }
    
    return obj;
  }
  
  // 根据路径获取值
  getValueByPath(obj, path) {
    return path.split('.').reduce((acc, key) => acc?.[key], obj);
  }
}
```

```javascript
class DataSourceManager {
  constructor() {
    this.dataSources = new Map();
    this.cache = new Map();
  }
  
  // 注册数据源
  register(dataSource) {
    this.dataSources.set(dataSource.id, dataSource);
    return dataSource;
  }
  
  // 获取数据源
  get(id) {
    return this.dataSources.get(id);
  }
  
  // 执行数据源
  async execute(id, context = {}) {
    const dataSource = this.get(id);
    if (!dataSource) {
      throw new Error(`数据源 ${id} 不存在`);
    }
    
    // 检查缓存
    if (dataSource.cache.enabled) {
      const cacheKey = this.getCacheKey(id, context);
      const cached = this.cache.get(cacheKey);
      
      if (cached && Date.now() - cached.timestamp < dataSource.cache.ttl) {
        return cached.data;
      }
    }
    
    // 执行数据源
    const data = await dataSource.execute(context);
    
    // 缓存数据
    if (dataSource.cache.enabled) {
      const cacheKey = this.getCacheKey(id, context);
      this.cache.set(cacheKey, {
        data,
        timestamp: Date.now()
      });
    }
    
    return data;
  }
  
  // 获取缓存键
  getCacheKey(id, context) {
    return `${id}_${JSON.stringify(context)}`;
  }
  
  // 清除缓存
  clearCache(id) {
    if (id) {
      for (const key of this.cache.keys()) {
        if (key.startsWith(id)) {
          this.cache.delete(key);
        }
      }
    } else {
      this.cache.clear();
    }
  }
  
  // 批量执行数据源
```

```javascript
    // 更新元素
    this.updateElement(elementId, value);
    
    return value;
  }
  
  // 更新所有绑定
  async updateAllBindings(context = {}) {
    const promises = Array.from(this.bindings.keys()).map(elementId => 
      this.updateBinding(elementId, context)
    );
    return Promise.all(promises);
  }
  
  // 根据路径获取值
  getValueByPath(obj, path) {
    if (!path) return obj;
    return path.split('.').reduce((acc, key) => acc?.[key], obj);
  }
  
  // 更新元素
  updateElement(elementId, value) {
    const element = document.querySelector(`[data-binding="${elementId}"]`);
    if (element) {
      if (element.tagName === 'INPUT') {
        element.value = value;
      } else {
        element.textContent = value;
      }
    }
  }
```

```javascript
class I18nManager {
  constructor() {
    this.currentLocale = 'zh-CN';
    this.locales = new Map();
    this.fallbackLocale = 'zh-CN';
    this.listeners = [];
  }
  
  // 注册语言包
  registerLocale(locale, messages) {
    this.locales.set(locale, messages);
  }
  
  // 设置当前语言
  setLocale(locale) {
    if (!this.locales.has(locale)) {
      console.warn(`语言包 ${locale} 不存在`);
      return;
    }
    
    this.currentLocale = locale;
    this.notifyListeners();
  }
  
  // 获取当前语言
  getLocale() {
    return this.currentLocale;
  }
  
  // 翻译文本
  t(key, params = {}) {
    const messages = this.locales.get(this.currentLocale);
    const fallbackMessages = this.locales.get(this.fallbackLocale);
    
    // 支持嵌套key,如'common.confirm'
    const keys = key.split('.');
    let value = messages;
    
    // 尝试从当前语言包获取
    for (const k of keys) {
      if (value && typeof value === 'object') {
        value = value[k];
      } else {
        value = undefined;
        break;
      }
    }
    
    // 如果当前语言包没有,尝试从fallback语言包获取
    if (value === undefined) {
      value = fallbackMessages;
      for (const k of keys) {
        if (value && typeof value === 'object') {
          value = value[k];
        } else {
          value = key;
          break;
        }
      }
    }
    
    // 替换参数
    if (typeof value === 'string' && params) {
      value = value.replace(/\{(\w+)\}/g, (match, param) => {
        return params[param] !== undefined ? params[param] : match;
      });
    }
    
    return value || key;
  }
  
  // 添加语言变化监听器
  addListener(listener) {
    this.listeners.push(listener);
    return () => {
      const index = this.listeners.indexOf(listener);
      if (index !== -1) {
        this.listeners.splice(index, 1);
      }
    };
  }
  
  // 通知监听器
  notifyListeners() {
    this.listeners.forEach(listener => listener(this.currentLocale));
  }
  
  // 格式化日期
  formatDate(date, format = 'YYYY-MM-DD') {
    const locale = this.currentLocale;
    const options = this.getDateOptions(format);
    return new Intl.DateTimeFormat(locale, options).format(new Date(date));
  }
  
  // 获取日期格式化选项
  getDateOptions(format) {
    const options = {};
    
    if (format.includes('YYYY')) {
      options.year = 'numeric';
    }
    if (format.includes('MM')) {
      options.month = '2-digit';
    }
    if (format.includes('DD')) {
      options.day = '2-digit';
    }
    if (format.includes('HH')) {
      options.hour = '2-digit';
    }
    if (format.includes('mm')) {
      options.minute = '2-digit';
    }
    
    return options;
  }
  
  // 格式化数字
  formatNumber(number, options = {}) {
    const locale = this.currentLocale;
    return new Intl.NumberFormat(locale, options).format(number);
  }
  
  // 格式化货币
  formatCurrency(amount, currency = 'CNY') {
    const locale = this.currentLocale;
    return new Intl.NumberFormat(locale, {
      style: 'currency',
      currency
    }).format(amount);
  }
}
```

```javascript
function parseI18nSchema(schema, locale) {
  const parsedSchema = JSON.parse(JSON.stringify(schema));
  
  function parseValue(value) {
    if (typeof value === 'string' && value.startsWith('${i18n.')) {
      const key = value.substring(7, value.length - 1);
      return schema.i18n[locale][key] || key;
    }
    
    if (Array.isArray(value)) {
      return value.map(parseValue);
    }
    
    if (typeof value === 'object' && value !== null) {
      const result = {};
      Object.keys(value).forEach(k => {
        result[k] = parseValue(value[k]);
      });
      return result;
    }
    
    return value;
  }
  
  if (parsedSchema.components) {
    parsedSchema.components = parsedSchema.components.map(comp => {
      if (comp.props) {
        comp.props = parseValue(comp.props);
      }
      return comp;
    });
  }
  
  return parsedSchema;
}
```

```javascript
// 防抖函数
function debounce(func, wait) {
  let timeout;
  return function executedFunction(...args) {
    const later = () => {
      clearTimeout(timeout);
      func(...args);
    };
    clearTimeout(timeout);
    timeout = setTimeout(later, wait);
  };
}

// 节流函数
function throttle(func, limit) {
  let inThrottle;
  return function(...args) {
    if (!inThrottle) {
      func.apply(this, args);
      inThrottle = true;
      setTimeout(() => inThrottle = false, limit);
    }
  };
}
```

```javascript
    });
```

```javascript
function LazyImage({ src, alt, ...props }) {
  const [isLoaded, setIsLoaded] = React.useState(false);
  const imgRef = React.useRef();
  
  React.useEffect(() => {
    const observer = new IntersectionObserver((entries) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          setIsLoaded(true);
          observer.unobserve(entry.target);
        }
      });
    });
    
    if (imgRef.current) {
      observer.observe(imgRef.current);
    }
    
    return () => {
      if (imgRef.current) {
        observer.unobserve(imgRef.current);
      }
    };
  }, []);
  
  return (
    <img
      ref={imgRef}
      src={isLoaded ? src : ''}
      alt={alt}
      {...props}
    />
  );
}
```

```javascript
// 请求缓存
class RequestCache {
  constructor(ttl = 5000) {
    this.cache = new Map();
    this.ttl = ttl;
  }
  
  async get(key, fetcher) {
    const cached = this.cache.get(key);
    
    if (cached && Date.now() - cached.timestamp < this.ttl) {
      return cached.data;
    }
    
    const data = await fetcher();
    this.cache.set(key, {
      data,
      timestamp: Date.now()
    });
    
    return data;
  }
  
  clear() {
    this.cache.clear();
  }
}

async function batchFetch(urls) {

  return Promise.all(promises);

// 请求队列
class RequestQueue {
  constructor(maxConcurrent = 5) {
    this.queue = [];
    this.running = 0;
    this.maxConcurrent = maxConcurrent;
  }
  
  async add(request) {
    return new Promise((resolve, reject) => {
      this.queue.push({ request, resolve, reject });
      this.process();
    });
  }
  
  async process() {
    while (this.running < this.maxConcurrent && this.queue.length > 0) {
      this.running++;
      const { request, resolve, reject } = this.queue.shift();
      
      try {
        const result = await request();
        resolve(result);
      } catch (error) {
        reject(error);
      } finally {
        this.running--;
        this.process();
      }
    }
  }
}
```

```javascript
class ProcessEngine {
  constructor() {
    this.processInstances = new Map();
    this.taskListeners = [];
  }
  
  // 启动流程实例
  startProcess(processDefinition, variables = {}) {
    const instance = {
      instanceId: `instance-${Date.now()}`,
      processId: processDefinition.processId,
      startTime: new Date(),
      variables: variables,
      currentNodeId: null,
      status: 'running',
      history: []
    };
    
    // 找到开始节点
    const startNode = processDefinition.nodes.find(n => n.type === 'start');
    if (startNode) {
      instance.currentNodeId = startNode.id;
      instance.history.push({
        nodeId: startNode.id,
        time: new Date()
      });
    }
    
    this.processInstances.set(instance.instanceId, instance);
    this.executeNextStep(instance, processDefinition);
    
    return instance;
  }
  
  // 执行下一步
  executeNextStep(instance, processDefinition) {
    const currentNode = processDefinition.nodes.find(n => n.id === instance.currentNodeId);
    
    if (!currentNode) return;
    
    switch (currentNode.type) {
      case 'start':
        // 开始节点自动流转到下一个节点
        this.findAndExecuteNextNode(instance, currentNode, processDefinition);
        break;
        
      case 'userTask':
        // 用户任务节点,等待用户操作
        this.createTask(instance, currentNode);
        break;
        
      case 'exclusiveGateway':
        // 排他网关,根据条件流转
        this.executeGateway(instance, currentNode, processDefinition);
        break;
        
      case 'end':
        // 结束节点
        instance.status = 'completed';
        instance.endTime = new Date();
        break;
    }
  }
  
  // 创建用户任务
  createTask(instance, node) {
    const task = {
      taskId: `task-${Date.now()}`,
      instanceId: instance.instanceId,
      nodeId: node.id,
      name: node.name,
      assignee: this.evaluateExpression(node.assignee, instance.variables),
      createTime: new Date(),
      status: 'pending',
      properties: node.properties || {}
    };
    
    // 通知任务监听器
    this.taskListeners.forEach(listener => {
      listener.onTaskCreated(task);
    });
  }
  
  // 完成任务
  completeTask(taskId, variables) {
    // 查找任务
    const task = this.findTask(taskId);
    if (!task) {
      throw new Error(`任务 ${taskId} 不存在`);
    }
    
    const instance = this.processInstances.get(task.instanceId);
    if (!instance) {
      throw new Error(`流程实例 ${task.instanceId} 不存在`);
    }
    
    // 更新变量
    Object.assign(instance.variables, variables);
    
    // 更新任务状态
    task.status = 'completed';
    task.completeTime = new Date();
    
    // 记录历史
    instance.history.push({
      nodeId: task.nodeId,
      time: new Date(),
      type: 'task-complete'
    });
    
    // 执行下一步
    const processDefinition = this.getProcessDefinition(instance.processId);
    const currentNode = processDefinition.nodes.find(n => n.id === task.nodeId);
    this.findAndExecuteNextNode(instance, currentNode, processDefinition);
  }
  
  // 执行网关
  executeGateway(instance, gatewayNode, processDefinition) {
    // 查找所有从网关出发的连接线
    const outgoingEdges = processDefinition.edges.filter(e => e.source === gatewayNode.id);
    
    // 评估每条连接线的条件
    for (const edge of outgoingEdges) {
      if (edge.condition) {
        const conditionResult = this.evaluateExpression(edge.condition, instance.variables);
        if (conditionResult) {
          // 条件满足,流转到目标节点
          instance.currentNodeId = edge.target;
          instance.history.push({
            nodeId: edge.target,
            time: new Date(),
            type: 'gateway-transition'
          });
          this.executeNextStep(instance, processDefinition);
          return;
        }
      }
    }
    
    // 没有满足的条件,流程结束
    instance.status = 'terminated';
  }
  
  // 查找并执行下一个节点
  findAndExecuteNextNode(instance, currentNode, processDefinition) {
    const outgoingEdge = processDefinition.edges.find(e => e.source === currentNode.id);
    
    if (outgoingEdge) {
      instance.currentNodeId = outgoingEdge.target;
      instance.history.push({
        nodeId: outgoingEdge.target,
        time: new Date()
      });
      this.executeNextStep(instance, processDefinition);
    }
  }
  
  // 表达式求值
  evaluateExpression(expression, variables) {
    // 简化实现,实际可以使用更强大的表达式引擎
    const func = new Function('variables', `with(variables) { return ${expression}; }`);
    return func(variables);
  }
  
  // 添加任务监听器
  addTaskListener(listener) {
    this.taskListeners.push(listener);
  }
}
```

```javascript
// 表单联动引擎
class FormLinkageEngine {
  constructor() {
    this.rules = [];
    this.formData = {};
    this.listeners = [];
  }
  
  // 添加联动规则
  addRule(rule) {
    this.rules.push(rule);
  }
  
  // 初始化表单数据
  initFormData(data) {
    this.formData = { ...data };
  }
  
  // 字段值变化时触发
  onFieldChange(fieldName, value) {
    // 更新表单数据
    this.formData[fieldName] = value;
    
    // 查找相关的联动规则
    const relatedRules = this.rules.filter(rule => rule.sourceField === fieldName);
    
    // 执行联动规则
    relatedRules.forEach(rule => {
      this.executeRule(rule, value);
    });
    
    // 通知监听器
    this.notifyListeners(fieldName, value);
  }
  
  // 执行联动规则
  executeRule(rule, sourceValue) {
    const context = {
      sourceValue,
      formData: this.formData
    };
    
    switch (rule.action) {
      case 'loadOptions':
        this.loadOptions(rule, context);
        break;
        
      case 'setValue':
        this.setValue(rule, context);
        break;
        
      case 'showHide':
        this.showHide(rule, context);
        break;
        
      case 'enableDisable':
        this.enableDisable(rule, context);
        break;
        
      case 'required':
        this.setRequired(rule, context);
        break;
    }
  }
  
  // 加载选项
  async loadOptions(rule, context) {
    const { api, params } = rule.config;
    
    // 替换参数中的变量
    const finalParams = this.replaceVariables(params, context);
    
    try {
      const response = await fetch(api, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(finalParams)
      });
      
      const options = await response.json();
      
      // 更新目标字段的选项
      this.updateFieldOptions(rule.targetField, options);
    } catch (error) {
      console.error('加载选项失败:', error);
    }
  }
  
  // 设置值
  setValue(rule, context) {
    const { expression } = rule.config;
    const value = this.evaluateExpression(expression, context);
    
    this.updateFieldValue(rule.targetField, value);
  }
  
  // 显示/隐藏
  showHide(rule, context) {
    const { condition, show } = rule.config;
    const shouldShow = this.evaluateExpression(condition, context);
    
    if (shouldShow) {
      this.showField(rule.targetFields, show);
    }
  }
  
  // 启用/禁用
  enableDisable(rule, context) {
    const { condition, enable } = rule.config;
    const shouldEnable = this.evaluateExpression(condition, context);
    
    this.enableField(rule.targetFields, shouldEnable);
  }
  
  // 设置必填
  setRequired(rule, context) {
    const { condition, required } = rule.config;
    const isRequired = this.evaluateExpression(condition, context);
    
    this.setFieldRequired(rule.targetField, isRequired);
  }
  
  // 替换变量
  replaceVariables(obj, context) {
    if (typeof obj === 'string') {
      return obj.replace(/\$\{(\w+)\}/g, (match, key) => {
        return context[key] || match;
      });
    }
    
    if (Array.isArray(obj)) {
      return obj.map(item => this.replaceVariables(item, context));
    }
    
    if (typeof obj === 'object' && obj !== null) {
      const result = {};
      Object.keys(obj).forEach(key => {
        result[key] = this.replaceVariables(obj[key], context);
      });
      return result;
    }
    
    return obj;
  }
  
  // 表达式求值
  evaluateExpression(expression, context) {
    const func = new Function('context', `with(context) { return ${expression}; }`);
    return func(context);
  }
  
  // 更新字段选项
  updateFieldOptions(fieldName, options) {
    const field = this.getFieldElement(fieldName);
    if (field) {
      // 更新下拉框选项
      if (field.tagName === 'SELECT') {
        field.innerHTML = options.map(opt => 
          `<option value="${opt.value}">${opt.label}</option>`
        ).join('');
      }
    }
  }
  
  // 更新字段值
  updateFieldValue(fieldName, value) {
    const field = this.getFieldElement(fieldName);
    if (field) {
      field.value = value;
      this.formData[fieldName] = value;
    }
  }
  
  // 显示/隐藏字段
  showField(fieldNames, show) {
    fieldNames.forEach(fieldName => {
      const field = this.getFieldElement(fieldName);
      const fieldWrapper = field?.closest('.form-item');
      
      if (fieldWrapper) {
        fieldWrapper.style.display = show ? '' : 'none';
      }
    });
  }
  
  // 启用/禁用字段
  enableField(fieldNames, enable) {
    fieldNames.forEach(fieldName => {
      const field = this.getFieldElement(fieldName);
      if (field) {
        field.disabled = !enable;
      }
    });
  }
  
  // 设置字段必填
  setFieldRequired(fieldName, required) {
    const field = this.getFieldElement(fieldName);
    if (field) {
      field.required = required;
    }
  }
  
  // 获取字段元素

    return document.querySelector(`[name="${fieldName}"]`);

  addListener(listener) {

    this.listeners.forEach(listener => {

    });
  }
}
```

```javascript
// 表单验证器
class FormValidator {
  constructor() {
    this.rules = {};
    this.formData = {};
  }
  
  // 添加验证规则
  addRules(fieldName, rules) {
    if (!this.rules[fieldName]) {
      this.rules[fieldName] = [];
    }
    this.rules[fieldName].push(...rules);
  }
  
  // 验证单个字段
  async validateField(fieldName, value) {
    const errors = [];
    const fieldRules = this.rules[fieldName] || [];
    
    for (const rule of fieldRules) {
      const error = await this.validateRule(value, rule, this.formData);
      if (error) {
        errors.push(error);
      }
    }
    
    return errors;
  }
  
  // 验证整个表单
  async validateForm(formData) {
    this.formData = formData;
    const allErrors = {};
    
    for (const fieldName in this.rules) {
      const errors = await this.validateField(fieldName, formData[fieldName]);
      if (errors.length > 0) {
        allErrors[fieldName] = errors;
      }
    }
    
    return {
      valid: Object.keys(allErrors).length === 0,
      errors: allErrors
    };
  }
  
  // 验证单个规则
  async validateRule(value, rule, formData) {
    switch (rule.type) {
      case 'required':
        if (!value || (typeof value === 'string' && value.trim() === '')) {
          return rule.message;
        }
        break;
        
      case 'minLength':
        if (value && value.length < rule.value) {
          return rule.message;
        }
        break;
        
      case 'maxLength':
        if (value && value.length > rule.value) {
          return rule.message;
        }
        break;
        
      case 'min':
        if (value !== undefined && value < rule.value) {
          return rule.message;
        }
        break;
        
      case 'max':
        if (value !== undefined && value > rule.value) {
          return rule.message;
        }
        break;
        
      case 'pattern':
        if (value && !new RegExp(rule.value).test(value)) {
          return rule.message;
        }
        break;
        
      case 'email':
        if (value && !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(value)) {
          return rule.message;
        }
        break;
        
      case 'custom':
        if (rule.validator) {
          const result = await rule.validator(value, formData);
          if (!result) {
            return rule.message;
          }
        }
        break;
        
      case 'async':
        if (rule.validator) {
          const result = await rule.validator(value, formData);
          if (!result.valid) {
            return result.message || rule.message;
          }
        }
        break;
```

```javascript
    if (!code) {

    }
    
    // 合并上下文
    const executionContext = { ...this.sandbox, ...context };
    
    // 执行代码
    const func = new Function('context', `
      with(context) {
        ${code}
      }
    `);
    
    return func(executionContext);

    return new Promise((resolve, reject) => {

      iframe.style.display = 'none';
      document.body.appendChild(iframe);
      
      // 设置沙箱
      const sandbox = this.sandbox;

      iframe.onload = () => {

        channel.port1.onmessage = (event) => {
          const { type, result, error } = event.data;
          
          if (type === 'result') {
            document.body.removeChild(iframe);
            resolve(result);
          } else if (type === 'error') {
            document.body.removeChild(iframe);
            reject(new Error(error));
          }
        };

        const code = this.platform.codeSnippets.get(snippetId);
        iframe.contentWindow.postMessage({
          type: 'execute',
          code,
          context
        }, '*', [channel.port2]);

            if (type === 'execute') {
```

```javascript
  async parseAndExecute(schema, context = {}) {
    // 注册代码片段
    if (schema.codeSnippets) {
      Object.keys(schema.codeSnippets).forEach(id => {
        this.platform.registerCodeSnippet(id, schema.codeSnippets[id]);
      });
    }

    this.bindComponentEvents(schema.components, context);
  }
  
  // 执行生命周期
  async executeLifeCycle(lifeCycle, context) {
    const phases = ['onMounted', 'onBeforeUpdate', 'onUpdated', 'onBeforeUnmount'];
    
    for (const phase of phases) {
      if (lifeCycle[phase]) {
        await this.executor.execute(lifeCycle[phase], context);
        await this.platform.executeLifeCycleHook(phase, context);
      }
    }
  }
  
  // 绑定组件事件
  bindComponentEvents(components, context) {
    components.forEach(comp => {
      if (comp.events) {
        Object.keys(comp.events).forEach(eventName => {
          const handlerCode = comp.events[eventName];
          
          // 创建事件处理器
          const handler = async (event) => {
            const eventContext = {
              ...context,
              $event: event,
              $component: comp
            };
            
            await this.executor.execute(handlerCode, eventContext);
          };
          
          // 绑定事件
          this.bindComponentEvent(comp.id, eventName, handler);
        });
      }
      
      // 递归处理子组件
      if (comp.children) {
        this.bindComponentEvents(comp.children, context);
      }
    });
  }
  
  // 绑定组件事件
  bindComponentEvent(componentId, eventName, handler) {
    // 根据组件ID查找DOM元素并绑定事件
    const element = document.querySelector(`[data-component-id="${componentId}"]`);
    if (element) {
      element.addEventListener(eventName.toLowerCase(), handler);
    }
  }
```

```javascript
    });
    
    return {
      valid: errors.length === 0,
      errors,
      warnings
    };
  }
  
  // 基础验证
  validateBase(schema, errors, warnings) {
    if (!schema.version) {
      errors.push({
        type: 'missing-version',
        message: 'Schema缺少版本号'
      });
    }
    
    if (!schema.pageId) {
      errors.push({
        type: 'missing-page-id',
        message: 'Schema缺少页面ID'
      });
    }
    
    if (!schema.components || schema.components.length === 0) {
      warnings.push({
        type: 'empty-components',
        message: 'Schema不包含任何组件'
      });
    }
  }
  
  // 组件验证
  validateComponents(schema, errors, warnings) {
    const componentIds = new Set();
    
    schema.components.forEach(comp => {
      // 验证组件ID
      if (!comp.id) {
        errors.push({
          type: 'missing-component-id',
          message: '组件缺少ID',
          component: comp
        });
      } else if (componentIds.has(comp.id)) {
        errors.push({
          type: 'duplicate-component-id',
          message: `组件ID重复: ${comp.id}`,
          component: comp
        });
      } else {
        componentIds.add(comp.id);
      }
      
      // 验证组件类型
      if (!comp.type) {
        errors.push({
          type: 'missing-component-type',
          message: '组件缺少类型',
          component: comp
        });
      } else if (!this.componentRegistry.has(comp.type)) {
        warnings.push({
          type: 'unknown-component-type',
          message: `未知的组件类型: ${comp.type}`,
          component: comp
        });
      }
      
      // 验证组件属性
      this.validateComponentProps(comp, errors, warnings);
      
      // 递归验证子组件
      if (comp.children) {
        this.validateComponents({ components: comp.children }, errors, warnings);
      }
    });
  }
  
  // 验证组件属性
  validateComponentProps(comp, errors, warnings) {
    const definition = this.componentRegistry.get(comp.type);
    
    if (!definition || !definition.propsSchema) {
      return;
    }
    
    const propsSchema = definition.propsSchema;
    const props = comp.props || {};
    
    // 验证必填属性
    if (propsSchema.required) {
      propsSchema.required.forEach(propName => {
        if (props[propName] === undefined) {
          errors.push({
            type: 'missing-required-prop',
            message: `缺少必填属性: ${propName}`,
            component: comp,
            property: propName
          });
        }
      });
    }
    
    // 验证属性类型
    if (propsSchema.properties) {
      Object.keys(props).forEach(propName => {
        const propValue = props[propName];
        const propSchema = propsSchema.properties[propName];
        
        if (propSchema) {
          const valid = this.validatePropType(propValue, propSchema);
          if (!valid) {
            errors.push({
              type: 'invalid-prop-type',
              message: `属性类型不匹配: ${propName}`,
              component: comp,
              property: propName,
              expected: propSchema.type,
              actual: typeof propValue
            });
          }
        }
      });
    }
  }
  
  // 验证属性类型
  validatePropType(value, schema) {
    switch (schema.type) {
      case 'string':
        return typeof value === 'string';
      case 'number':
        return typeof value === 'number';
      case 'boolean':
        return typeof value === 'boolean';
      case 'array':
        return Array.isArray(value);
      case 'object':
        return typeof value === 'object' && value !== null && !Array.isArray(value);
      default:
        return true;
    }
  }
}
```

```javascript
// 沙箱环境
class Sandbox {
  constructor() {
    this.allowedGlobals = {
      console: console,
      Math: Math,
      Date: Date,
      JSON: JSON,
      Array: Array,
      Object: Object,
      String: String,
      Number: Number,
      Boolean: Boolean
    };
    
    this.builtins = ['eval', 'Function', 'setTimeout', 'setInterval', 'fetch', 'XMLHttpRequest'];
  }
  
  // 创建隔离环境
  createContext(context = {}) {
    const sandbox = { ...this.allowedGlobals, ...context };
    
    // 禁用危险的全局对象
    this.builtins.forEach(name => {
      delete sandbox[name];
    });
    
    return sandbox;
  }
  
  // 安全执行代码
  async execute(code, context = {}) {
    const sandbox = this.createContext(context);
    
    try {
      // 使用Proxy拦截访问
      const sandboxProxy = new Proxy(sandbox, {
        get(target, prop) {
          if (prop in target) {
            return target[prop];
          }
          
          // 阻止访问原型链上的危险属性
          if (prop === 'constructor' || prop === '__proto__') {
            return undefined;
          }
          
          return undefined;
        },
        
        set(target, prop, value) {
          if (prop in target) {
            target[prop] = value;
            return true;
          }
          return false;
        }
      });
      
      // 执行代码
      const func = new Function('sandbox', `
        with(sandbox) {
          ${code}
        }
      `);
      
      return func(sandboxProxy);
    } catch (error) {
      console.error('代码执行失败:', error);
      throw new Error('代码执行被阻止: ' + error.message);
    }
  }
}
```

```javascript
class AuditLogger {
  constructor() {
    this.logs = [];
    this.maxLogs = 10000;
  }
  
  // 记录日志
  log(action, context) {
    const logEntry = {
      id: this.generateId(),
      timestamp: new Date(),
      action,
      userId: context.userId,
      sessionId: context.sessionId,
      ip: context.ip,
      userAgent: context.userAgent,
      data: context.data,
      result: context.result
    };
    
    this.logs.push(logEntry);
    
    // 限制日志数量
    if (this.logs.length > this.maxLogs) {
      this.logs.shift();
    }
    
    // 异步保存到服务器
    this.saveToServer(logEntry);
  }
  
  // 生成ID
  generateId() {
    return Date.now().toString(36) + Math.random().toString(36).substr(2);
  }
  
  // 保存到服务器
  async saveToServer(logEntry) {
    try {
      await fetch('/api/audit-logs', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(logEntry)
      });
    } catch (error) {
      console.error('保存审计日志失败:', error);
    }
  }
  
  // 查询日志
  query(filters) {
    return this.logs.filter(log => {
      if (filters.action && log.action !== filters.action) return false;
      if (filters.userId && log.userId !== filters.userId) return false;
      if (filters.startTime && log.timestamp < filters.startTime) return false;
      if (filters.endTime && log.timestamp > filters.endTime) return false;
      return true;
    });
  }
  
  // 导出日志
  export(filters) {
    const logs = this.query(filters);
    const csv = this.convertToCSV(logs);
    return csv;
  }
  
  // 转换为CSV

      log.id,
      log.timestamp.toISOString(),
      log.action,
      log.userId,
      log.ip,
      JSON.stringify(log.data)
    ]);
    
    return [headers, ...rows].map(row => row.join(',')).join('\n');
  }
```

### 5. 细粒度权限控制

```javascript
// 权限模型
class PermissionModel {
  constructor() {
    this.roles = new Map();
    this.permissions = new Map();
    this.userRoles = new Map();
  }
  
  // 创建角色
  createRole(roleId, roleName) {
    this.roles.set(roleId, {
      id: roleId,
      name: roleName,
      permissions: new Set()
    });
  }
  
  // 添加权限
  addPermission(permissionId, permissionDef) {
    this.permissions.set(permissionId, {
      id: permissionId,
      resource: permissionDef.resource,
      action: permissionDef.action,
      conditions: permissionDef.conditions || []
    });
  }
  
  // 为角色分配权限
  assignPermissionToRole(roleId, permissionId) {
    const role = this.roles.get(roleId);
    if (role) {
      role.permissions.add(permissionId);
    }
  }
  
  // 为用户分配角色
  assignRoleToUser(userId, roleId) {
    if (!this.userRoles.has(userId)) {
      this.userRoles.set(userId, new Set());
    }
    this.userRoles.get(userId).add(roleId);
  }
  
  // 检查用户是否有权限
  hasPermission(userId, permissionId, context = {}) {
    // 获取用户角色
    const userRoleIds = this.userRoles.get(userId) || new Set();
    
    // 检查角色是否有权限
    for (const roleId of userRoleIds) {
      const role = this.roles.get(roleId);
      if (role && role.permissions.has(permissionId)) {
        // 检查权限条件
        const permission = this.permissions.get(permissionId);
        if (this.checkConditions(permission.conditions, context)) {
          return true;
        }
      }
    }
    
    return false;
  }
  
  // 检查条件
  checkConditions(conditions, context) {
    return conditions.every(condition => {
      const { field, operator, value } = condition;
      const actualValue = context[field];
      
      switch (operator) {
        case '==':
          return actualValue === value;
        case '!=':
          return actualValue !== value;
        case '>':
          return actualValue > value;
        case '<':
          return actualValue < value;
        case 'in':
          return Array.isArray(value) && value.includes(actualValue);
        default:
          return true;
      }
    });
  }
}

// 使用示例
const permissionModel = new PermissionModel();

// 创建角色
permissionModel.createRole('admin', '管理员');
permissionModel.createRole('editor', '编辑');
permissionModel.createRole('viewer', '查看者');

// 添加权限
permissionModel.addPermission('page:edit', {
  resource: 'page',
  action: 'edit',
  conditions: []
});

permissionModel.addPermission('page:edit:own', {
  resource: 'page',
  action: 'edit',
  conditions: [
    { field: 'pageCreator', operator: '==', value: '${userId}' }
  ]
});

permissionModel.addPermission('page:view', {
  resource: 'page',
  action: 'view',
  conditions: []
});

// 分配权限
permissionModel.assignPermissionToRole('admin', 'page:edit');
permissionModel.assignPermissionToRole('editor', 'page:edit:own');
permissionModel.assignPermissionToRole('editor', 'page:view');
permissionModel.assignPermissionToRole('viewer', 'page:view');

// 分配角色
permissionModel.assignRoleToUser('user-001', 'admin');
permissionModel.assignRoleToUser('user-002', 'editor');
permissionModel.assignRoleToUser('user-003', 'viewer');

// 检查权限
console.log(permissionModel.hasPermission('user-001', 'page:edit'));  // true
console.log(permissionModel.hasPermission('user-002', 'page:edit', { pageCreator: 'user-002' }));  // true
console.log(permissionModel.hasPermission('user-003', 'page:edit'));  // false
```

```javascript
// 权限控制组件
const PermissionGuard = ({ user, permission, children, fallback = null }) => {
  const hasPermission = checkPermission(user, permission);
  
  if (hasPermission) {
    return children;
  } else {
    return fallback;
  }
};

// 权限指令
const permissionDirective = {
  mounted(el, binding) {
    const { user, permission } = binding.value;
    const hasPermission = checkPermission(user, permission);
    
    if (!hasPermission) {
      el.style.display = 'none';
    }
  }
};

// 使用示例
<PermissionGuard
  user={currentUser}
  permission={{ resource: 'page', action: 'edit' }}
  fallback={<div>无权限访问</div>}
>
  <Button>编辑页面</Button>
</PermissionGuard>

// 或者使用指令
<button v-permission="{ user: currentUser, permission: { resource: 'page', action: 'edit' } }">
  编辑页面
</button>
```
