# 2. 小程序性能优化做了哪些事情？

**答案：**

#### 1. 代码层面优化

- **减少包体积**：使用分包加载、按需引入
- **代码压缩**：启用 minified 选项

#### 2. 渲染层面优化

```javascript
// 减少 setData 调用
// 不好的做法
this.setData({ count: 1 });
this.setData({ count: 2 });
this.setData({ count: 3 });

// 好的做法
this.setData({ count: 3 });

// 使用路径更新
this.setData({ 'user.name': 'newName' });
```

#### 3. 网络请求优化

- **请求合并**：批量处理请求
- **数据缓存**：使用 wx.setStorageSync
- **图片懒加载**：使用 lazy-load 属性

#### 4. 用户体验优化

- **骨架屏**：提升加载体验
- **预加载**：使用 wx.preloadPage
- **分包预下载**：优化启动速度

#### 5. 内存优化

- 及时释放资源
- 使用 WeakMap 避免内存泄漏
