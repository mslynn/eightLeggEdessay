# 6. 【代码题】查找有序数组中数字最后一次出现的位置

**答案：**

```javascript
function findLastPosition(nums, target) {
  let left = 0;
  let right = nums.length - 1;
  let result = -1;

  while (left <= right) {
    const mid = Math.floor((left + right) / 2);

    if (nums[mid] === target) {
      result = mid;
      left = mid + 1; // 继续向右搜索
    } else if (nums[mid] < target) {
      left = mid + 1;
    } else {
      right = mid - 1;
    }
  }

  return result;
}

// 测试
console.log(findLastPosition([1, 2, 2, 2, 3, 4], 2)); // 3
console.log(findLastPosition([1, 2, 3, 4, 5], 3)); // 2
```

**时间复杂度**：O(log n)
